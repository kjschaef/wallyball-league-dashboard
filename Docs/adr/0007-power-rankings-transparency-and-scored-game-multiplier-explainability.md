# Power Rankings Transparency, Scored vs. Unscored Multipliers, and Calibration UX

To resolve player confusion regarding skill rating updates versus quarterly standings, the dashboard establishes explicit transparency mechanisms across the UI while strictly preserving the canonical "Power Ranking" terminology:
1. **Interactive Educational Guide**: An on-demand "How Power Rankings Work" dialog explains the distinction between quarterly Season Race standings (resetting quarterly) and permanent career Power Rankings, team-average expected win probabilities, and skill tier benchmarks.
2. **Scored vs. Unscored Multiplier Explainability**: The system clearly contrasts scored games (which scale up to a 2.0x Margin of Victory multiplier based on point spreads) with unscored games (which use a 1.0x baseline multiplier), clarifying why entering exact point scores generates significantly higher rating momentum.
3. **Provisional Calibration Transparency**: New players display explicit progress badges (`PROV (X/10)`) with calibration tooltips explaining the 10-game rapid stabilization phase ($K=48$).
4. **Contextual Match Breakdown**: Match details display pre-match win odds, scored vs. unscored categorization, per-game multiplier badges, and plain-English takeaways explaining rating deltas.
